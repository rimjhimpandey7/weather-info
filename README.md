# Weather Information App

## Project Overview
The Weather Information App is a web application that provides real-time weather information for any city. It fetches live weather data using a Weather API and stores the user's search history using Local Storage.

## Features
- Search weather by city name
- View real-time weather information
- Display temperature, humidity, wind speed, and weather condition
- Store search history
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Weather API
- Local Storage

##  How to Run
1. Download or clone this repository.
2. Open `weather-detection.html` in your browser.
3. Enter a city name to view the current weather.
